# AEGIS-CD 变化检测演示系统 · 项目实现说明

## 完整版（可写入比赛「项目实现」部分）

本系统是 AEGIS-CD 轻量化遥感变化检测模型的交互式演示与验证平台，完整实现「双时相影像输入 → 二值变化图输出 → 定量指标评估」的推理闭环，用于直观展示模型的检测效果与工程落地能力。

**模型**：AEGIS-CD（Run13 E4_IndDiff_SCDS），参数量 3.61 M。采用 Siamese MobileNetV2 共享编码器 + HFEA 层次特征增强 + 尺度独立的 EAOM 差异编码（小波域边缘感知对齐）+ RepDW 可重参数化解码器 + EdgeGate 边界细化 + 尺度解耦独立预测头（native SCDS 深度监督）。在 LEVIR / WHU / SYSU / CDD 四个公开数据集的测试集上 F1 分别为 91.46% / 94.24% / 83.88% / 97.15%。

**技术架构**：后端基于 Flask + PyTorch（CPU 推理），前端为原生 HTML/CSS/JS 单页应用，无需额外构建工具即可在浏览器运行。加载训练产出的 best_model 权重，推理预处理（Scale → Normalize → ToTensor fixed）与训练/测试阶段严格一致，保证推理结果可复现。

**核心功能**：
1. 多数据集权重一键切换（LEVIR / WHU / SYSU / CDD）；
2. 支持样例库选取与自定义双时相图片上传两种输入方式；
3. 可视化输出时相 1、时相 2 原图、二值变化图与概率热力图；
4. 支持预测变化区域与原始影像的叠加对比（滑条交互）；
5. 实时输出 F1、IoU、Precision、Recall、OA、变化比例、推理耗时等定量指标，并展示各数据集测试集参考指标。

**使用流程**：选择数据集权重 → 选取样例或上传双时相影像 → 一键推理 → 查看变化图与指标 → 拖动叠加滑条对比变化区域，整体操作可在一屏内完成，适合竞赛答辩现场演示。

## 口播版（视频解说词）

这是 AEGIS-CD 轻量化遥感变化检测系统的演示。输入同一区域不同时相的两张遥感影像，模型就能自动预测出二值变化图，标出新增或消失的地物。系统内置了 LEVIR、WHU、SYSU、CDD 四个数据集共 32 组样例，也支持上传自己的图片。点击样例后，右侧会同时显示时相一、时相二、预测变化图和概率热力图，下方实时给出 F1、IoU、精度、召回等指标，还可以拖动滑条把变化区域叠加到原图上做对比。整个模型只有 361 万参数，四个数据集的测试 F1 分别达到 91.46%、94.24%、83.88% 和 97.15%。
